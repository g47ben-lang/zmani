# SaveBridge בלי הפרוקסי היקר — שרת הורדות חינמי משלך

התוסף **SaveBridge** מוסיף כפתור הורדה בתוך YouTube, אבל הוא עצמו לא מוריד כלום —
הוא שולח את הקישור (ואת ה-Cookies שלך) לשרת שמריץ `yt-dlp`+`ffmpeg` ומחזיר את
הקובץ. בגרסה המקורית השרת הזה היה `extsync.com` — שירות **בתשלום**.

התיקייה הזו מחליפה את השרת בתשלום ב**שרת חינמי משלך** שרץ ב-Google Colab (או בכל
מקום אחר), ומפנה את התוסף אליו. התוצאה: אותו כפתור, אותה חוויה — בלי לשלם על פרוקסי,
וה-Cookies שלך נשארים אצלך ולא אצל צד שלישי.

```
דפדפן + תוסף  ──►  השרת החינמי שלך (Colab)  ──►  yt-dlp + ffmpeg  ──►  הקובץ חוזר אליך
```

---

## ⚠️ שני דברים שחשוב לדעת לפני שמתחילים

1. **IP של ענן מול YouTube.** פרוקסי בתשלום עולה כסף כי הוא נותן כתובת IP *ביתית*.
   שרת חינמי בענן משתמש ב-IP של דאטה-סנטר, ולפעמים YouTube מבקש ממנו אימות
   *("Sign in to confirm you're not a bot")*. התוסף שולח את ה-Cookies שלך לשרת,
   ועם חשבון מחובר זה עובד ברוב המקרים — אבל לא 100% מושלם. זה המחיר של "חינם".
2. **פרטיות.** התוסף המקורי שולח את ה-Cookies של חשבון Google שלך ל-`extsync.com`.
   כאן הם נשלחים **רק לשרת שלך** ונמחקים בסוף כל הורדה. זו סיבה טובה לא להיות תלוי
   בשרת של מישהו אחר.

## שלב 2 — התקן/עדכן את התוסף

התיקייה `extension-patch/` מכילה 4 קבצים מעודכנים שמחליפים את השרת בתשלום בשרת שלך:

| קובץ | מה שונה |
|------|---------|
| `background.js` | קורא את כתובת השרת מההגדרות במקום `extsync.com`, בלי חתימות/סודות. |
| `options.html` + `options.js` | מחזיר את שדה **"כתובת השרת"** + **"טוקן"** בהגדרות. |
| `manifest.json` | מרשה גישה לכתובות של שרתים חינמיים (trycloudflare וכו'). |

**איך מחילים:**

1. קח את תיקיית התוסף שהחבר שלח לך (זו שיש בה `background.js`, `content.js`, `manifest.json`…).
2. העתק לתוכה את 4 הקבצים מ-`extension-patch/`, **דרוס** את הקיימים.
3. ב-Chrome: כתובת `chrome://extensions` → הפעל **Developer mode** (פינה עליונה) →
   **Load unpacked** → בחר את תיקיית התוסף. (אם הוא כבר טעון — לחץ **↻ Reload**.)

> שאר הקבצים (`content.js`, `injected.js`, `content.css`, האייקונים) — נשארים כמו שהם.

## שלב 3 — חבר וחפש

1. לחץ על אייקון התוסף → **הגדרות** (או `chrome://extensions` → פרטים → אפשרויות תוסף).
2. הדבק את הכתובת מ-Colab בשדה **כתובת השרת**. אם הגדרת סיסמה (`SB_TOKEN`) ב-Colab —
   הדבק אותה בשדה **טוקן**; אחרת השאר ריק.
3. לחץ **שמור וחבר**. הנקודה במצב החיבור צריכה להפוך לירוקה — **מחובר ✔**.
4. ודא שאתה **מחובר ל-YouTube** בדפדפן, כנס לסרטון, ולחץ על כפתור ההורדה.

## אופציות איכות

הכפתור מציע: וידאו (איכות מיטבית / 1080p / 720p / 480p), אודיו בלבד (MP3), ו-3GP
(קובץ קטן לטלפון). יש גם אודיו/כתוביות בעברית מתפריט הכפתור. הכל מטופל בשרת דרך
`yt-dlp` — הפורמטים ממופים ב-`server/app.py`.

## להריץ במקום אחר (לא Colab)

`server/app.py` הוא שרת FastAPI רגיל. על כל מכונה/VPS/שרת-ענן חינמי עם `python3`+`ffmpeg`:

```bash
cd youtube-extension/server
./run.sh                     # מאזין על 0.0.0.0:9797, פתוח
SB_TOKEN=secret ./run.sh     # דורש טוקן = secret
PORT=8080 ./run.sh           # פורט אחר (Cloud Run מגדיר PORT אוטומטית)
```

אם תריץ על שרת תמיד-פעיל (Cloud Run / Oracle Always Free / VPS), תקבל כתובת קבועה
שלא צריך לעדכן כל פעם. הגדר `SB_TOKEN` כדי שלא כל אחד יוכל להשתמש בשרת שלך, והדבק את
אותו טוקן בהגדרות התוסף. אם הכתובת אינה תת-דומיין מוכר, ייתכן שתצטרך להוסיף אותה
ל-`host_permissions` ב-`manifest.json` (השרת שולח CORS פתוח, אז ברוב המקרים זה כבר עובד).
